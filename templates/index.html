About Alzheimer’s Disease

Alzheimer’s disease is a progressive neurological disorder that leads to memory loss, confusion, and changes in behavior. It is the most common cause of dementia — a continuous decline in thinking, behavioral, and social skills that affects a person’s ability to function independently.

Early diagnosis can help slow the progression and improve the quality of life. Our project leverages deep learning techniques using the VGG16 model to automatically analyze brain MRI scans and detect the level of dementia with remarkable accuracy.

Dataset Categories

Non Demented

Healthy brain with no signs of Alzheimer’s or memory loss.

Very Mild Demented

Slight memory lapses; very early stage of Alzheimer’s disease.

Mild Demented

Noticeable memory and reasoning problems; early Alzheimer’s symptoms.

Moderate Demented

Clear cognitive decline and significant memory impairment.
