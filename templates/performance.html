Model Performance Analysis

📌 What is Accuracy?

Accuracy refers to how often the model correctly predicts the output labels. Higher accuracy indicates better model performance. In diagnosis-related projects, accuracy measures the system's success in identifying disease cases correctly.

📌 What is Loss?

Loss measures how far the model's predictions are from the actual labels. Lower loss value means that the model is learning effectively. The goal during training is to minimize the loss.

📌 What are Epochs?

An epoch refers to one complete pass through the entire training dataset. More epochs allow the model to learn better features, but too many can cause overfitting.
